Things I’ve shipped & worked on.

FLUXJIVA

Real-time platform · AI

An on-machine platform for real-time monitoring of live machine data with an integrated AI assistant. I built its core chat service in FastAPI, using RAG over company knowledge and live machine data with Anthropic Claude Sonnet, then deployed the service on GCP Cloud Run.

  • Migrated from WebSockets to Server-Sent Events, eliminating timeouts under heavy load and streaming live measurements to many concurrent clients with minimal overhead.
  • Implemented a caching layer for Overall Equipment Effectiveness (OEE) calculations, reducing InfluxDB CPU utilization from over 90% to a 20–40% average and reducing request failures under load.
  • Built secure user authentication and token management with Django’s auth system.
FastAPI Uvicorn Django RAG Claude SSE GCP Cloud Run

DRIMS

Digital Record Information Management System · Client: Brilliant Corporation

A Digital Record Information Management System where I developed two Python backend services and enhanced existing ones by resolving critical bugs, adding features and improving overall platform performance. I replaced the default Bottle development server with Gunicorn for selected services, enabling concurrent request handling and reducing container downtime.

  • Reduced TIFF-to-PDF peak memory by roughly 93% (3.8 GB to 250 MB) and generated PDF size by 90% (76 MB to 8 MB) by replacing Pillow with img2pdf.
  • Diagnosed a memory-exhaustion bug that blocked database-entry creation and caused a batch daemon to repeatedly re-upload files; stopped duplicate AWS Batch jobs and stabilized the pipeline.
  • Deployed, monitored and troubleshot cloud-hosted services on AWS to improve stability and scalability.
